# Personal Portfolio Website

This project is a personal portfolio website developed to showcase my academic journey, technical skills, projects, experiences, and certifications as an Informatics Engineering student.

The website highlights my work in Mobile Development, Web Development, Augmented Reality (AR), and 3D Modeling through an interactive and responsive user interface built with HTML, CSS, and JavaScript.

## Features
- Modern and responsive design
- About Me section
- Skills & Technologies showcase
- Featured Projects gallery
- Experience & Certifications section
- Contact Information

## Tech Stack
- HTML5
- CSS3
- JavaScript
